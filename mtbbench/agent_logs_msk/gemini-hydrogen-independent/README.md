# Gemini UI experiment

183 separate questions, one fresh chat per question, using current-stage context and files. UI displayed model name Hydrogen; exact backend/version is unverified. `gemini_results.jsonl` and `.csv` retain prompts, visible model replies, labels and metadata. Preliminary accuracy was 131/183 (71.6%). This is not the sequential agent protocol; external search availability and temporal leakage were not controlled.
